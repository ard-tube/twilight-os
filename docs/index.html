🖥️ Virtual Machine Support

Run Twilight OS directly inside Windows or macOS without modifying your physical disk partitions.

Windows / Linux

Oracle VirtualBox & VMware

Ideal for testing Twilight OS safely inside Windows 10/11 or Ubuntu.

  • OS Type: Linux → Arch Linux (64-bit)
  • Base Memory: 4096 MB (4 GB) or more
  • Processors: 2 to 4 CPU Cores
  • Enable EFI: Required System → Motherboard → Check "Enable EFI"
  • Graphics: Display → 128 MB VRAM + Check "Enable 3D Acceleration"
  • Virtual Disk: 25 GB+ (VDI / Dynamic)
💡 Tip: In VirtualBox, set Graphics Controller to VMSVGA for smooth KDE Plasma 6 Wayland rendering.
Apple Silicon (M1/M2/M3/M4) & Intel

UTM, VMware Fusion & VirtualBox

Native ARM64 build for Apple Silicon Macs — buttery-smooth near-bare-metal performance.

  • Apple Silicon (M-Series): Use UTM or VMware Fusion in Virtualize mode (ARM64)
  • Intel Macs: Use VirtualBox or VMware Fusion (x86_64)
  • Memory: 4096 MB (4 GB RAM allocated)
  • Cores: 2 to 4 vCPU cores (full native hypervisor speed)
  • Display: VirtIO-GPU or VMware SVGA (Wayland accelerated)
  • Formats: Bootable UEFI ISO (twilight-os-*-aarch64.iso) or 1-click UTM disk (.qcow2)
🍎 Apple Silicon Tip: In UTM, click "+ Create VM", select Virtualize → Linux, and attach the ARM64 ISO or import the QCOW2 image.
