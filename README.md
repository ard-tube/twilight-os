# Twilight OS

An Arch Linux based operating system with the KDE Plasma desktop.

> Status: early development (alpha). Rebuilt from scratch.

## Build

The ISO is built automatically with GitHub Actions.
- Manual build: Actions tab -> "Build Twilight OS ISO" -> Run workflow
- Release: push a tag like `v0.1.0-alpha`

Based on Arch Linux's `archiso` `releng` profile.
